## 2. Explicit Policy Gaps, Discrepancies & Human Approval Gates (`Part 03 §3.2`)

1. **`D04-10` — Read Receipts & Ephemeral Typing (`DEFERRED BY APPROVED DECISION`)**: Read receipts remain OFF by default; last-seen, online presence, and typing history are omitted everywhere. Owner-only private `unreadCount` updates privately for the recipient without notifying the sender.
2. **`D-P35-01` / `Doc 06 OD-07` — Text Message Character Limit (`NEEDS HUMAN DECISION`)**: Conflicting values across specs/prior code (`1,000` enforced in runtime API/Web, `2,000` in pre-3.5 `@saymyname/validation`, and `4,000` placeholder in `Doc 06 §17` OpenAPI, while `OD-07` marks the limit `OPEN`). Harmonized across `@saymyname/validation`, `@saymyname/api`, and `@saymyname/web` at `MAX_TEXT_MESSAGE_LENGTH = 1000` pending explicit Product approval in `docs/decisions/DECISION_REGISTER.md`.
3. **`D-P35-02` / `D04-12` — Voice-Note File Size Cap & Retention (`NEEDS HUMAN DECISION`)**: Duration cap is locked at `60` seconds (`Doc 02 §4.3`). File size guardrail defaults to `VOICE_NOTE_DEFAULT_MAX_BYTES = 5 * 1024 * 1024` (overridable via `VOICE_NOTE_MAX_BYTES`), pending explicit Product + Engineering sign-off in `docs/decisions/DECISION_REGISTER.md`.
4. **`D04-11` & `ADR-10` — Message Retention, Deletion & E2EE (`DEFERRED BY APPROVED DECISION`)**: Uses `service_encrypted` PostgreSQL persistence and private R2 storage with zero E2EE UI claims and no auto-purge or unilateral message-deletion mutation.
