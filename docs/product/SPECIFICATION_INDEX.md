## Rules

- Record version, approval/status and last reviewed date for every source.
- Use the domain document for its subject. Use the approved decision log for later changes.
- Do not silently edit source documents. Submit controlled updates through review.
- Create stable traceability IDs in the project index without renaming the source requirements.
